Manual install

The easy way: inside Luma Core, open the Luma Shop and install a pack from Texture packs. It downloads, checks and installs the pack for you. This page is for installing by hand.

Every texture pack can also be downloaded here and installed yourself, in the Azahar emulator on a PC or Android device, or straight into Luma Core's own folder.

Downloads

Each download is one zip file. Inside is a single folder named after the game's ID, with the pack's textures in it.

Before you start

  • You need your own copy of the game. A pack only changes how the game looks; it contains no game.
  • Packs are for emulators. They do nothing on a real 3DS or DS.
  • Leave room to unzip. Keep about twice the pack's size free: once for the zip, once for the unzipped files. You can delete the zip afterwards.
  • Don't rename anything. The emulator finds each texture by its file name, and each pack's pack.json belongs to that pack.
  • Big packs need a capable device. If a game stutters or runs out of memory with a pack installed, remove the pack.

3DS packs: Azahar on PC

  1. In Azahar's game list, right-click the game and choose Open Custom Texture Location. A folder opens whose name is the game's ID, inside load/textures.
  2. Go up one level, to the textures folder.
  3. Unzip the pack there. You should end up with load/textures/<game ID>/ containing pack.json and thousands of .png files. If the game's folder already existed and is empty, let the unzip merge into it.
  4. In Azahar, open Emulation > Configure > Graphics > Utility and tick Use custom textures. Preload is optional: faster in game, but a slower start and more memory.
  5. Start the game.

3DS packs: Azahar on Android

  1. Unzip the pack with a file manager. You get one folder named after the game's ID.
  2. Move that folder into Azahar's load/textures folder, so the path ends in load/textures/<game ID>/.
  3. In Azahar's settings, open Graphics and turn on Use custom textures.
  4. Start the game.

3DS packs: Luma Core by hand

Luma Core keeps its packs in its own folder on your storage, and looks there first.

  1. Unzip the pack with a file manager. You get one folder named after the game's ID.
  2. Move that folder into LumaCore/textures, so the path is LumaCore/textures/<game ID>/.
  3. Make sure HD texture packs are switched on: it is step 4 of the first-time setup, and you can run the setup again from Settings > General > Library.
  4. Start the game. To play without the pack, highlight the game, press X, choose Forged and set it to Off.

Luma Core checks a hand-installed pack's files, and treats a copy that matches as one of ours. Don't mix files from another pack into the same folder.

DS packs

The Pokémon HeartGold and Mario Kart DS packs are made for Luma Core's DS player. They don't work in other DS emulators.

  1. Unzip the pack. You get one folder named after the game's code: IPKE for HeartGold, AMCE for Mario Kart DS.
  2. Move that folder into LumaCore/textures, so the path is LumaCore/textures/IPKE/ or LumaCore/textures/AMCE/.
  3. Highlight the game in Luma Core, press X and choose Forged. Pick AYN Thor optimized on a Thor, or Basics on any other device.
  4. The game's HD pack can also be switched on or off on its own in its Game settings.

Dragon Quest XI pack

  • This pack was made from the English-patched game, so install it on a patched copy. It installs like any other 3DS pack above.
  • It is for the game's 3D mode only, and it is a work in progress.
  • The small title screen add-on in the downloads table holds the title screens for each patch version. Unzip it into the same place as the main pack and let it merge.
  • When the pack is active, the title screen shows an "HD texture pack" line above the English patch version.

Check your download

These are large files. To confirm one arrived intact, compare its SHA-256 checksum with the one listed under Checksum on that pack's page.

  • Windows: open a terminal in the download folder and run certutil -hashfile the-file.zip SHA256
  • macOS or Linux: run shasum -a 256 the-file.zip

If the result doesn't match, download the file again.

Removing a pack

Delete the game's folder from load/textures (Azahar) or LumaCore/textures (Luma Core). Your game and saves are not touched. To keep the files but stop using them, switch Use custom textures off in Azahar, or set the game's Forged to Off in Luma Core.

If it doesn't work

  • Nothing looks different. Check that the folder is named exactly after the game's ID and that pack.json sits directly inside it, not one folder deeper. A common slip is ending up with <game ID>/<game ID>/.
  • Still nothing. Check that Use custom textures is on in Azahar, or that the game's Forged setting is on in Luma Core.
  • A different region of the game. A 3DS pack is tied to the game ID in the table. Another region's release has a different ID and won't pick the pack up.
  • The game stutters or closes. The device is short on memory for that pack. Turn off Preload, or remove the pack.
